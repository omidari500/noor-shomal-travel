## الصور
تم ربط صور المعالم المعروفة بملفات Wikimedia Commons المرتبطة باسم المكان، بينما استُخدمت صور بحثية/مرجعية خارجية لبعض المناظر الطبيعية التي تحتاج إلى استبدالها لاحقاً بصور أصلية أو صور مرخصة محلياً.

**مهم:** قبل الاستخدام التجاري، راجع شروط ترخيص كل صورة خارجية ونسب الإسناد المطلوبة.  
المحتوى كله باللغة العربية وواجهة الموقع RTL.
